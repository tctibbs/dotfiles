# Showcase

What this configuration changes, one page per feature. Where the change is
visual, the page shows the same content twice — stock and configured.

| Page | Covers |
|------|--------|
| [tab-bar.md](tab-bar.md) | Tabs showing which coding agent is running and what it is doing |
| [directories.md](directories.md) | Reopening tabs in the directories they were in |

Planned, roughly in order of usefulness: the starship prompt, the modern CLI
replacements against their coreutils equivalents, tmux, VS Code, and the
Windows Terminal counterpart.

Regenerate the images with `scripts/capture-showcase.sh tab-bar` — captured
from a real window, so they cannot drift from what the config does. macOS only.
